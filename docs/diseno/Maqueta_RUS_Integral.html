Vincular aplicación y extensión

  1. Abre SITFA en Chrome y mantén la pestaña abierta.
  2. Abre la página de conexión de la extensión desde esa pestaña.
  3. Copia allí el código temporal que mostrará la aplicación local.
  4. Mantén abiertas ambas pestañas durante el lote.
